# Peoplebot-Megabot OS Installer Tools

## Repository Overview

This project provides a complete TFTP/PXE boot infrastructure for installing and recovering Peoplebot and Megabot systems. The repository contains ISO files, boot configurations, and automation scripts for network-based deployment. Supports Legacy BIOS, Modern BIOS, UEFI BIOS, and UEFI Secure Boot BIOS.

## Folder Structure

- **isos/** - Contains ISO images for various system installations and recovery tools
- **extracted/** - Holds extracted boot content from larger ISO files
- **pxelinux.cfg/** - PXE boot configuration files generated automatically (Legacy BIOS)
- **uefi_menu.txt** - iPXE menu for UEFI systems (generated by isolisting.py)
- **Boot files** - TFTP server files required for PXE networking

### Required Boot Files by BIOS Type

| BIOS Type | Required Files | Purpose |
|-----------|---------------|---------|
| **Legacy BIOS** | `pxelinux.0`, `ldlinux.c32`, `libutil.c32`, `menu.c32`, `memdisk` | Standard syslinux PXE boot |
| **Modern BIOS / UEFI BIOS** | `ipxe.efi` | iPXE UEFI boot |
| **UEFI Secure Boot BIOS** | `shimx64.efi` + `mmx64.efi` | Secure Boot compliant boot (shim chains directly to iPXE) |

### How to Obtain UEFI Boot Files

The `isolisting.py` script automatically downloads necessary UEFI files if missing:

1. **ipxe.efi** - iPXE bootloader for UEFI
   - Source: Arch Linux `ipxe` package (configured via `UEFI_IPXE_URL` in `.env`)
   - Alternative: https://boot.ipxe.org or build from source at https://github.com/ipxe/ipxe

2. **shimx64.efi** + **mmx64.efi** - UEFI Secure Boot shim and MOK manager
   - Source: Arch Linux `shim` package (configured via `UEFI_SHIM_URL` in `.env`)
   - Alternative: Your distro's firmware repository

3. **undionly.kpxe** + **ipxe.pxe** - iPXE bootloaders for Legacy BIOS
   - Source: https://boot.ipxe.org (downloaded automatically)

### PXE Menu Options

#### Legacy BIOS Menu (`pxelinux.cfg/default`)
- Boots directly via syslinux/pxelinux
- Supports memdisk boot for small ISOs (<150MB)
- Supports extracted kernel boot for large ISOs

#### UEFI Menu (`uefi_menu.txt`)
- iPXE-based menu for UEFI systems
- Option 1: Boot from local hard drive
- Option 2: Memdisk boot (small ISOs)
- Option 3: Low-RAM extracted mode boot
- Press ESC to enter iPXE shell

## Purpose

This setup enables diskless booting and installation of operating systems over the network, ideal for:
- Laboratory environments
- Mass deployment of systems
- Recovery and maintenance operations
- Low-RAM system booting via memdisk or extracted kernels

## Usage

- Small ISOs (<150MB, configurable via PXE_MAX_MEMDISK_MB) can boot directly via memdisk (Legacy BIOS) or Option 2 (UEFI)
- Large ISOs are extracted for Low-RAM mode booting
- Configure dhcp and tftp services as described in the setup
- Run `isolisting.py` to generate/update boot menus
- For UEFI systems, ensure `ipxe.efi`, `shimx64.efi`, and `mmx64.efi` are in the TFTP directory
- Copy `.env.example` to `.env` and modify values for your environment

## Environment Configuration

The `isolisting.py` script reads configuration from the `.env` file (with sensible defaults). Key configurable options:

| Variable | Default | Description |
|-----------|---------|-------------|
| `TFTP_DIR` | `/home/luminaire/Downloads/tftp` | Base directory for all PXE files |
| `ISO_DIR_NAME` | `isos` | Subdirectory containing ISO files |
| `EXTRACT_DIR_NAME` | `extracted` | Subdirectory for extracted ISO content |
| `CFG_DIR_NAME` | `pxelinux.cfg` | Subdirectory for PXE config files |
| `CFG_FILE_NAME` | `default` | Default PXE menu configuration filename |
| `PXE_INTERFACE` | `enp45s0` | Network interface for dnsmasq |
| `PXE_SERVER_IP` | `192.168.254.2` | TFTP/HTTP server IP address |
| `PXE_DHCP_START` | `192.168.254.100` | Start of DHCP IP range |
| `PXE_DHCP_END` | `192.168.254.200` | End of DHCP IP range |
| `PXE_HTTP_PORT` | `8085` | HTTP port for squashfs file streaming |
| `PXE_MAX_MEMDISK_MB` | `150` | Maximum ISO size (MB) for memdisk boot |

See `.env.example` for a complete reference of all configuration options.

### Running with Custom Configuration

```bash
# Copy example and modify
cp .env.example .env
nano .env

# Run the script with custom settings
python3 isolisting.py
```
